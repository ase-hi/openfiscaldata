  • 1005번 → 조치원역 하차 → 조치원역 801번 → 국무조정실(한뜰마을 3단지) 하차 → 도보 1분

  • BRT B3 → 정부세종청사 남측 하차 → 221번 → 국무조정실(한뜰마을 3단지) 하차 → 도보 1분
  • BRT B1·B2·B3 → 정부세종청사 북측 하차 → 도보 1분

  • 경부고속도로 → 부산방면 진입 → 천안분기점 → 천안·논산고속도로 → 북공주분기점 → 당진·대전고속도로 → 서세종IC → 단국세종빌딩
