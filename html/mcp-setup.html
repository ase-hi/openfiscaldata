AI 도구별 MCP 설정 방법

원격 MCP 서버 URL을 AI 도구의 커넥터에 등록하는 방식입니다.

❶ Claude (Anthropic)
  1. 로그인 → 좌측 하단 [설정]
  2. [커넥터] → [맞춤 설정]
  3. [+] → [커스텀 커넥터 추가]
  4. 이름 + 재정 MCP 서버 URL 입력 → [추가]
  5. 승인 요청 → '항상 허용'
  6. 채팅창에 재정데이터 질문
❷ AntiGravity (Google Gemini)
  1. 앱 설치(antigravity.google)·구글 로그인
  2. 설정파일 mcp_config.json 열기
  3. 재정 MCP 서버 URL 추가 후 저장(url·serverURL·timeout·trust)
  4. 채팅창에 재정데이터 질문
❸ ChatGPT (OpenAI)
  1. 로그인 → [설정] → 개발자 모드 켜기
  2. [커넥터/플러그인] 추가
  3. 재정 MCP 서버 URL 입력 (인증 없음)
  4. [+] → 커넥터 선택 후 질문
  • 상세 절차 및 설정 화면 예시는 'MCP 설정 가이드'를 다운로드하여 참고할 수 있습니다.
  • AI 도구 사용 요금·계정 조건은 각 도구 공식 안내를 확인해주세요.
  • 설정 위치와 메뉴 명칭 등은 각 AI 도구 업데이트에 따라 달라질 수 있습니다. 제공사 공식 설명을 확인해주세요.
